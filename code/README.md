# Код проекта

Код сгруппирован по назначению:

- `ielts_judge/data` — преобразование датасетов и их первичный анализ.
- `ielts_judge/aes` — ordinal AES-модель и метрики её оценки.
- `ielts_judge/llm` — получение ответов LLM и fine-tuning.
- `ielts_judge/panda` — загрузка общей модели (`PandaModel`), генерация инсайтов (`InsightGenerator`) и retrieval/оценка (`RetrievalEvaluator`). `Panda.py` сохраняет прежний фасад `PANDA`.
- `ielts_judge/evaluation` — агрегация результатов и анализ оценок LLM.
- `tools` — вспомогательные скрипты для исследовательских материалов.

`main.py` остаётся точкой запуска исследовательского pipeline. `config.yaml` хранит переключатели стадий, `paths.yaml` — пути к входным данным, результатам и ресурсам, а `resources/ielts_criteria.yaml` — идентификаторы критериев, их названия и сокращённые band-дескрипторы. Промпты и преобразование исторических меток читают критерии из этого ресурса. Относительные пути из `paths.yaml` считаются от корня проекта.

Запускайте из корневой папки `src`:

```powershell
python .\code\main.py
```

Для чтения и записи YAML требуется PyYAML. JSON оставлен для ответов моделей и сохранённых результатов экспериментов.

Эта структура организует существующий код; API-сервис из архитектуры MVP здесь пока не реализован.
