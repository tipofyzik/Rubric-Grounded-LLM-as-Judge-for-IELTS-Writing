# Tools

The Kaggle builders put each notebook together with the data and files it needs. They cover [essay model training](BuildAesKaggle.py), [PANDA note generation](BuildPandaKaggle.py) and [model comparison](BuildEvaluationKaggle.py).

Use the notebook and ZIP from the same build. The [Kaggle guide](../notebooks/README.md) lists the commands, required inputs and exact output filenames.

[`PromptImage.py`](PromptImage.py) draws figures for the research write-up.
