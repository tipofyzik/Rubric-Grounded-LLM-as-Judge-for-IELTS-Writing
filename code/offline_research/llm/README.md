# LLM

[`LLMResponseObtainer.py`](LLMResponseObtainer.py) sends scoring prompts to a local or hosted model and saves the replies. The saved replies can be compared with the dataset scores.

[`LLMFineTuner.py`](LLMFineTuner.py) supports the historical fine-tuning workflow. Use `research bundle-legacy` to prepare that [Kaggle notebook](../notebooks/README.md#legacy). The benchmark in the published report runs through [`research evaluate`](../evaluation/README.md).
