# Model evaluation

Do a rubric, similar examples and a first estimate help small language models score essays more accurately? This code compares prompt variants on the same test essays and measures how closely each set of scores matches the dataset.

[`EvaluateModels.py`](../EvaluateModels.py) runs the comparison and saves the predictions. [`Report.py`](Report.py) and [`Plots.py`](Plots.py) turn those predictions into tables and charts. You can also rebuild the report from a saved run.
