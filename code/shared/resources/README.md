# App resources

Edit these files to change what people see in the app or what the judge uses to score an essay.

- [`demo_examples.json`](demo_examples.json) contains the sample questions and essays.
- [`ielts_criteria.yaml`](ielts_criteria.yaml) contains the rubric.
- [`model_registry.yaml`](model_registry.yaml) lists the judge model and its settings.
- [`locales/`](locales/README.md) contains the labels and messages shown in the app.
