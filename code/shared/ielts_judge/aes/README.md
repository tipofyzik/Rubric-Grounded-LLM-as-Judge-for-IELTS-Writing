# Aes

Load the accepted ordinal AES bundle and perform essay-only predictions. Checkpoints are separate artifacts. Training belongs to offline_research.

| File | Responsibility |
|---|---|
| [__init__.py](__init__.py) | Automated essay scoring models and their evaluation utilities. |
| [Inference.py](Inference.py) | Complete AES bundles: local reconstruction, integrity and semantic checks. |
| [OrdinalRegression.py](OrdinalRegression.py) | Essay-only AES: four ordinal heads and integer scores in dataset order. |
