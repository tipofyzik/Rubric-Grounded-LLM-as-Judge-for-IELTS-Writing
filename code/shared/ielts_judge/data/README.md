# Data

Read and validate prepared releases, stable IDs, hashes and experiment membership shared with runtime artifact checks. Data preparation is explicitly invoked by research tools.

| File | Responsibility |
|---|---|
| [__init__.py](__init__.py) | Dataset transformation and descriptive analysis. |
| [Experiment.py](Experiment.py) | Full-train reference membership and reproducible selections from source test. |
| [Preparation.py](Preparation.py) | Offline preparation of the two local IELTS sources, without model imports. |
