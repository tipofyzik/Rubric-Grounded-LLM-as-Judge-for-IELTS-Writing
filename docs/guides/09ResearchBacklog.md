# Preserved research and deferred work


The engineering release preserves the accepted AES/corpus formats and the previously executed baseline. No new training, insights generation, embedding build, ingestion, repeatability, robustness or full model benchmark is required to complete this demo-focused iteration.

The research component retains preparation, AES training, PANDA generation/build/import, local-context model evaluation and historical notebook tooling. It is loaded only by explicit research commands. The runtime uses accepted artifacts.

Future experiments must freeze IDs, settings and expected behavior before execution. The discussed 100 essays × 3 repeats and 60 robustness cases remain unapproved proposals. Modified Task/Essay variants do not automatically inherit the original source labels. The used test pool is not an untouched final holdout.

Read the [baseline protocol](../model_evaluation_protocol.md), [baseline report](../model_evaluation_report.md) and [research block](../../code/offline_research/README.md) before resuming this work.
