# Research backlog

The [baseline](../model_evaluation_report.md) leaves repeatability and robustness open.

- **Repeatability.** Fix the essay IDs, settings and repeat count before inference.
- **Robustness.** Record case IDs, input hashes and expected behavior. Score modified inputs against the original behavior or collect new expert labels.
- **Future tuning.** Reserve a separate evaluation pool before inspecting the results.
